# System Design

## Architecture Style

Pragmatic microservices architecture.

## Core Services

- api-gateway
- auth-service
- clinic-service
- patient-service
- followup-service
- notification-service

## Frontend

- Next.js
- Tailwind CSS

## Backend

- Spring Boot 3
- Java 21

## Infrastructure

- Docker Compose
- PostgreSQL
- RabbitMQ

## Multi-Tenancy

Shared application with tenant isolation using clinicId.

## Deployment

Initial deployment on Hetzner VPS using Docker Compose.
