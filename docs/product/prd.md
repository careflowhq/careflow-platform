# Product Requirements Document (MVP)

## MVP Goal

Validate that automated follow-up increases patient retention and reduces operational overload in private clinics.

## Primary Users

- doctors
- assistants
- clinic administrators

## Core MVP Features

### Authentication
- login
- role management
- multi-tenant access

### Patient Management
- create patient
- update patient
- appointments

### Follow-Up
- appointment reminders
- post-consultation follow-up
- inactivity reminders

### Alerts
- no response alerts
- risk alerts
- inactive patients

### Notifications
- WhatsApp integration
- notification workflows

## Non-Goals

- electronic health records
- AI diagnosis
- prescriptions
- advanced analytics

## Success Metrics

- response rate
- patient return rate
- assistant time reduction
- follow-up completion rate
