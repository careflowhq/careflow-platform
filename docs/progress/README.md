## Cuándo actualizar

- Nueva implementación mergeada o verificada localmente
- Nuevo servicio o integración
- Issue importante resuelto
- Cambio de arquitectura o ADR

## Convención

1. Editar **Última actualización** y resumen de sesión
2. Añadir fila en **Historial de implementaciones**
3. Marcar checkboxes en **Próximos pasos**
4. Pasar contexto a ChatGPT/Cursor abriendo este folder + `docs/adr/` + `docs/architecture/`
